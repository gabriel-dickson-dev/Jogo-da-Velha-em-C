# Jogo da Velha em C
Implementação do clássico jogo da velha em linguagem C para execução via terminal.

## Funcionalidades
Modo Jogador vs. Jogador: Partidas para dois jogadores no mesmo computador.

## Validação: Checagem de posições válidas e ocupadas.

Detecção de Fim de Jogo: Verificação automática de vitória ou empate.

## Como Compilar e Executar
Compile o código com o GCC:

## Bash
gcc jogo_da_velha.c -o jogo_da_velha
Execute o programa:

Linux / macOS: ./jogo_da_velha

Windows: jogo_da_velha.exe

## Como Jogar
O tabuleiro possui uma grade 3x3.

O Jogador 1 utiliza X e o Jogador 2 utiliza O.

Insira a posição desejada a cada rodada. Alinhe três símbolos para vencer.
